# 政务办事_港澳通行证办理知识库

版本：kb_20260615_business_fix

用途：作为 Dify 政务办事知识库导入文档，用于支撑港澳通行证、签注类型、费用时限和商务签注问答。具体办理要求以当地公安出入境管理部门最新公告、窗口说明和官方政务服务平台为准。

## G签和L签有什么区别？

G签通常指个人旅游签注，L签通常指团队旅游签注。

常见说明：
- G签适用于开放个人赴港澳旅游的地区，通常可按个人旅游方式出行。
- L签属于团队旅游签注。实际通关要求可能因口岸、地区和政策调整而变化。
- 用户持有哪类签注，应以港澳通行证签注页显示为准。
- 是否需要跟团、是否可自行通关，应以当前口岸和出入境管理部门最新要求为准。

建议回答要点：
- 先解释“G签=个人旅游签注，L签=团队旅游签注”。
- 不要绝对化承诺所有口岸都相同。
- 提醒用户出行前确认签注目的地、次数和有效期。

## 办理港澳通行证多少钱？

往来港澳通行证证件工本费通常为 60元/证。

签注费用通常另收，常见一次有效签注为 15元/件。不同签注类型、次数和地区执行口径可能不同，具体以当地公安出入境管理部门公布的收费标准为准。

建议回答要点：
- 明确提到“60元/证”和“15元”。
- 说明签注费用可能另计。
- 提醒以当地窗口或官方平台最新收费为准。

## 商务签注可以停留多久？

内地居民申请往来港澳商务签注后，每次在香港或者澳门的停留时间通常不超过 14天。

办理商务签注时，一般需要按照当地公安出入境管理部门要求提交与商务事由相关的单位证明、登记备案信息或其他补充材料。不同地区、不同备案状态和不同签注次数的要求可能不同，建议办理前先通过当地出入境窗口、政务服务平台或官方咨询电话确认。

常见提醒：
- 商务签注不同于个人旅游签注或团队旅游签注。
- 是否可以办理、多次签注条件、备案要求和材料清单，以当地出入境管理部门最新要求为准。
- 如果只是旅游、探亲或其他目的，不应选择商务签注。
