请为一个 Android Jetpack Compose App 生成一套移动端中保真 UI 设计稿。

项目名称：粤同心-湾区中老年助手。

目标用户：
中老年用户，主要用于港澳通关、港澳通行证/签注咨询、材料准备、口岸信息查看、智能问答、家属协助。

项目定位：
这不是完整政务系统，而是一个适老化港澳通关与办事辅助 App。核心目标是帮助老人理解：

1. 通关前需要准备什么；
2. 通关中遇到问题怎么问；
3. 通关后/办理后如何保存材料清单、草稿和家属确认信息。

设计参考：
参考深圳 i口岸类微信小程序的信息架构，包括口岸卡片、服务宫格、通关时间、状态标签、官方可信感。
但不要照搬复杂政务公告、新闻动态、实时数据图表。
请把复杂政务服务改成适老化、低层级、任务导向的 UI。

技术背景：
Android 项目使用 Kotlin + Jetpack Compose。
当前已有 FastAPI + Dify + Qwen 的问答链路。
UI 设计不需要修改后端接口逻辑，只做前端页面与交互展示。

整体设计原则：

1. 适老化优先：大字号、大按钮、高对比、少层级。
2. 首页不要做成长条信息流。
3. 使用底部导航栏 + 首页大卡片组合。
4. 页面内容尽量短，避免一次展示太多问题。
5. 常见问题使用分类 Tab + 折叠卡片。
6. 静态资料类页面只展示内容，不做复杂处理。
7. AI 回答区域要适合手机阅读。
8. 保留文字输入 fallback，语音识别失败时可手动输入。
9. 服务页和我的页的宫格内容第一版只展示，不跳转，点击后弹 Toast。
10. 口岸状态和预计等待时间为 mock 演示数据，详情页底部提示“状态为演示数据，请以现场公告为准”。

视觉风格：
温和、清晰、可信、适老化。
主色使用政务蓝。
绿色表示正常/已完成。
橙色表示提醒。
红色表示紧急帮助。
卡片圆角较大，按钮高度不低于 48dp。
正文默认大字号。
避免密集小字。

页面尺寸：
Android 手机竖屏，390 x 844。

请生成以下页面 Frame：

1. HomeScreen 首页
2. ChatScreen 智能问答页
3. ServiceScreen 服务页
4. MyScreen 我的页
5. PortDetailScreen 口岸详情页

首页 / 问答 / 服务 / 我的
