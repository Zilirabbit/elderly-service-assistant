# 2026-05-24 UI 静态还原阶段总结

## 本阶段目标

本阶段只负责按照 `ElderCareApp/img` 下已提供截图，还原当前明确给出的页面显示效果。

实现范围限定为静态 UI 展示和基础页面跳转，不实现真实业务功能、接口调用、数据库、AI 问答、语音识别、语音播报、登录注册等逻辑。

## 已完成页面

1. 首页 / 智能助手页
   - 顶部标题区：“粤同心-湾区中老年助手”“您的智能生活帮手”
   - 字体入口、播报语言、目的地/出发地、方向选择
   - 助手介绍卡片、操作指南入口
   - 材料清单、翻译、紧急呼叫等功能按钮
   - 常见问题分类、问题输入框、发送和语音提问按钮
   - 子女/客服帮手、我的材料清单入口

2. 字体大小选择页
   - 展示小字体、中字体、大字体、超大字体四个选项
   - 默认高亮“大字体”
   - 点击只切换本页选中样式，不改变全局字号

3. 材料清单事项选择页
   - 展示六个事项卡片：办理港澳通行证、港澳通行证续签、社保医保转移、老年证办理、老年补贴申请、过关材料准备
   - 点击卡片只弹出静态提示，不生成真实材料清单

4. 操作指南页当前可见部分
   - 展示“操作指南”标题
   - 使用本地裁剪图片展示第 1 步示意图
   - 展示“第一步：点击语音提问”和说明文案
   - 展示进度点、`1 / 5`、上一步、下一步、关闭按钮
   - 不补全其余 4 步内容
