# UI方案

你是一个 Android Jetpack Compose UI/UX 设计助手。请根据下面的产品说明，帮我整理一份适合 Codex 实现的 Android App UI 规格文档。

项目名称：粤同心-湾区中老年助手

## 项目定位：

面向中老年用户的港澳通关与办事辅助 App。核心目标不是做完整政务系统，而是帮助老人理解：

1. 通关前需要准备什么；
2. 通关中遇到问题怎么问；
3. 通关后/办理后如何保存材料清单、草稿和家属确认信息。

## 整体 UI 原则：

1. 适老化优先：大字号、大按钮、高对比、少层级。
2. 首页不要做成长条信息流。
3. 功能入口采用底部导航栏 + 首页大卡片组合。
4. 页面内容尽量短，避免一次展示太多问题。
5. 常见问题采用分类 + 折叠卡片。
6. 静态资料类页面只展示内容，不做复杂处理。
7. 每段重要文字后面可放一个小喇叭按钮，用于朗读。
8. AI 即时回答可以调用后端/Dify，回答区域要适合手机阅读。
9. 保留文字输入 fallback，语音识别失败时可手动输入。
10. 不要修改现有后端接口逻辑，只设计前端页面与跳转。

## 整体页面架构

App 使用底部导航栏，建议包含 4 个一级入口：

1. 首页
   - 聚合核心功能入口；
   - 展示通关前、通关中、通关后三个阶段卡片；
   - 提供语音提问和文字提问入口。

2. 问答
   - 展示聊天式 AI 问答页面；
   - 支持文字输入；
   - 支持语音输入；
   - 支持回答朗读；
   - 支持追问建议；
   - 支持跳转到材料清单或表单预填。
   - 可以参考 Figma / 现有LLM对话模型界面 等现有模板。

3. 服务
   - 出发/到达 服务
   - 其他服务

4. 我的
   - 展示字体设置；
   - 展示我的材料清单；
   - 展示表单草稿；
   - 展示家属确认入口；
   - 展示操作指南。

### 首页布局

页面名称：Home / 首页

布局方式：

- 整体为竖向滚动页面。
- 顶部固定标题区。
- 中间为三阶段功能卡片。
- 底部使用 BottomNavigationBar 保持一级导航。

页面从上到下包含：

1. 顶部标题区
   - 左侧：
     - App 名称：粤同心
     - 副标题：湾区中老年助手
   - 右侧：
     - 字体按钮
     - 可选：语言切换按钮 ：简体 / 繁体 / English
     - 全局偏好设置区
     - 播报语言：普通话 / 粤语
     - 这些状态会影响 FAQ、材料清单、AI 回答和语音播报语言。

2. 顶部下侧
   - 地区：香港 / 澳门 / 全部
   - 方向：去往港澳 / 返回内地 / 全部
   - 影响主要问答入口卡片下方口岸内容展示

3. 主要问答入口卡片
   - 标题：您好，我可以帮您查政策、准备材料、陪您办理
   - 主按钮：点击提问
   - 小按钮：📖 查看操作指南
   - 点击提问 → 跳转 ChatScreen / 聊天式 AI 问答页面
   - 点击查看操作指南 → 跳转 GuideScreen

4. 口岸内容展示区
   - 卡片组件
   - 展示 2-3 个常用口岸，不要一次展示太多：
     - 深圳湾口岸
       - 开放时间：6:30 - 24:00
       - 正在获取定位。导航。两端对齐。
       - 当前：正常
       - 按钮：查看详情
     - 福田口岸
       - 开放时间：6:30 - 22:30
       - 当前：正常
       - 按钮：查看详情
   - 底部按钮：查看全部口岸

5. 常见问题区
   - 标题：常见问题
   - 分类 Tab：
     - 全部
     - 证件办理
     - 签注续签
     - 通关流程
     - 交通出行
   - 问题卡片默认只展示 3-5 个。
   - 点击“展开更多”才显示更多问题。
   - 点击某个问题 → 跳转 ChatScreen，并自动把问题发送给 AI。

6. 底部导航栏
   - 首页
   - 问答
   - 服务
   - 我的

#### 口岸详情页 UI

页面结构：

1. 顶部信息卡
   - 口岸名称：深圳湾口岸
   - 当前状态：正常
   - 开放时间：6:30 - 24:00
   - 预计等待：约 15 分钟
   - 更新时间：今天 09:30

2. 重要提醒卡
   - 请确认港澳通行证和有效签注
   - 建议提前准备身份证件
   - 高峰时段可能排队，请预留时间
   - 每条提醒右侧放小喇叭按钮

3. 过关步骤
   - 第一步：到达口岸
   - 第二步：准备证件
   - 第三步：通过边检
   - 第四步：前往香港侧交通接驳

4. 相关服务卡片组

#### 操作指南页 GuideScreen：

- 使用左右滑动幻灯片卡片
- 共 5 张操作步骤卡片
- 每张卡片包含图标 / 插图、标题、说明、小喇叭按钮
- 小喇叭按钮第一版只弹 Toast：“朗读功能暂未开放”
- 底部显示进度点、当前步骤 1/5
- 提供“上一步”“下一步 / 完成”“关闭”
- 第 1 页禁用“上一步”
- 第 5 页“下一步”改为“完成”
- 点击“关闭”或“完成”返回首页

### 问答页面布局

1. 仿造 Codex 对话页面结构
2. 顶部栏
   - 返回
   - 标题：智能问答
   - 右侧：字体

3. 侧边栏
   - 对话历史记录

4. AI 回答卡片
   - 内容
   - 底部，朗读

5. 底部输入栏
   - 左侧：语音输入。
     - 先显示成一个待确认气泡：点“正确，继续”后，再转成正式用户消息。在文本后添加朗读。
   - 中间：输入框
   - 右侧：发送按钮

6. 发送后状态
   - 显示：正在查询官方资料，请稍候……
   - 禁止重复点击发送

7. 失败状态
   - 网络失败：网络好像不太稳定，请稍后再试
   - 没查到：资料中暂时没有明确答案，建议咨询人工窗口。

### 服务详细页

1. 出发/到达服务
   - 通关流程、预约停车、交通出行、特殊人群预约、志愿者呼叫、客服电话、视频通关

2. 其他服务
   - 养老资源、医疗资源、旅游资源等等

3. 其他
   - 正常展示“出发/到达服务”和“其他服务”宫格
   - 所有宫格项第一版不跳转
   - 点击任一服务项 Toast：“该功能暂未开放”
