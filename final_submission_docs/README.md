# 最终提交文档阅读顺序

本目录为项目最终提交材料的精简版文档集合，建议按以下顺序阅读：

1. `01_系统架构说明.md`：先了解 Android 前端、FastAPI 后端、Dify/RAG、ASR/TTS 与本地数据模块的整体关系。
2. `02_功能模块说明.md`：查看各功能模块的用途、入口、当前实现状态和涉及文件。
3. `03_知识库与数据来源说明.md`：查看当前知识库范围、FAQ 与 RAG 分工、数据来源边界和维护建议。
4. `04_后续优化计划.md`：查看短期、中期、长期优化方向，以及上线和交付前需要补充的材料。

本目录仅整理最终提交文档，不包含 API 接口说明、部署说明、测试报告或项目总说明。
